# Editorial fonts

Self-hosted Google Fonts for consistent typography without third-party font requests.
Downloaded 2026-10-02. Original WOFF2 files are unmodified.

- DM Sans, normal 400–700, Latin subset: https://fonts.google.com/specimen/DM+Sans
- Newsreader, normal 400–600, optical size 6–72, Latin subset: https://fonts.google.com/specimen/Newsreader
- Newsreader, italic 400–600, Latin subset (quotes, English captions)
- DM Mono, normal 400 and 500, Latin subset (dates, metadata): https://fonts.google.com/specimen/DM+Mono
- Mrs Saint Delafield, normal 400, Latin subset (nav signature): https://fonts.google.com/specimen/Mrs+Saint+Delafield
- Noto Serif SC, normal 400–600, full Unicode-range subsets: https://fonts.google.com/noto/specimen/Noto+Serif+SC

The accompanying OFL files contain the SIL Open Font License and copyright notices.
`src/fonts.css` maps each font's original Unicode ranges to these local files; browsers load only the ranges required by the visible text. Keep the ranges and font files together when updating.
